以下のプロンプトを `codex exec --sandbox danger-full-access` で実行してください。

Bash ツールで次のコマンドを実行してください：

```
codex exec --sandbox danger-full-access "$ARGUMENTS"
```

実行後、出力結果をユーザーにわかりやすく伝えてください。
